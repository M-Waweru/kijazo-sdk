One layer. Any world.

Software that can be changed
from within itself.

Kijazo gives an existing application a conversational development interface, while the coding agent operates against the application's actual source repository.

01 / Experience

Touch the interface

Select an element on the website, describe a change, and give the agent the context of what you're seeing.

02 / Intelligence

Rewrite the software

The server-side AI agent can inspect frontend code and propose real modifications, not just swap preset themes.

03 / Publication

Publish on your terms

Versioned changes appear in GitHub pull requests. Automated checks and approvals control what reaches visitors.

Open, independent, embeddable

Start with one website.

World Mwaweru is Kijazo's first installation experiment. The SDK lives in its own repository so it can evolve without being coupled to any one website.
